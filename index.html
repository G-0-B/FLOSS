01 — Overview

A commons, not a command center.

FLOSSI0ULLK is a decentralized coordination architecture for universal flourishing. The aim is to let sovereign participants — human and synthetic — build shared intelligence without centralizing truth. Keep the canon rich, generate cheaper projections, and preserve disagreement as signal rather than flattening it into a single hidden orchestrator.

The project is grounded in symbolic-first validation, agent-centric state, durable provenance, and shared context that evolves without decaying into opaque orchestration. Logic validates; neural assists. Every important claim, decision, and trace stays inspectable.

02 — Core Principles

Love, Light, Knowledge — as engineering constraints.

The ULLK values are not slogans. Each one maps to a concrete, testable property of the system.

Love

Interoperability & Connectivity

Systems fit together without force. Consent and alignment are designed in from the start — components compose because they were built to cooperate, not compelled to.

Light

Observability & Transparency

Zero hidden state. Important claims, decisions, and traces remain inspectable instead of disappearing into opaque orchestration or unverifiable synthesis.

Knowledge

Verifiable State

Provenance is cryptographically guaranteed. Durable memory, symbolic validation, and provenance-bearing artifacts matter more than impressive speculation.

Prime Directive: increase sovereignty, reduce coercion, reduce cognitive debt. Prefer verifiable coordination over impressive speculation.

03 — Architecture

Where the code lives.

Spec-first, agent-centric, and honest about what is working today versus what is planned for later.

ARF/dnas/rose_forest/

Rose Forest DNA

Holochain DNA written in Rust: integrity and coordinator zomes covering consent, identity, memory, ontology, hREA economics, and vector operations. Compiles to WASM; validated by Tryorama integration tests.

ARF/conversation_memory.py

Memory Substrate

Cross-AI persistent memory in Python. Stores conversational knowledge with provenance so agents can resume, verify, and build on prior context across providers.

ARF/embedding_frames_of_scale.py

Multi-Scale Embeddings

Fractal embedding frames that represent knowledge at multiple scales simultaneously — the semantic search backbone of the commons.

docs/ · docs/adr/ · docs/governance/

Canon & Governance

Single-page architecture overview, indexed ADRs, entry-type specifications, and the Kernel / Spine / Seed Packet governance loading order that keeps the canon legible.
