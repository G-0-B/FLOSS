## What this is
The **Optimal Verifiable Context Artifact (OVCA) v0.1** is the complete,
upgradable, cryptographically-provenance-anchored context continuation
artifact for the FLOSSI0ULLK / Rose Forest project.

It is designed to be pasted into any local agent (Claude Code, Ollama,
GPT-5, Gemini, local LLM via LM Studio, etc.) to instantly load the
full project context and continue work without re-researching.

## Upgrading this artifact
Per the spine's UpgradableArtifact contract, any upgrade must:
- Increment version (semver)
- Set `supersedes: ["ovca-flossi0ullk-context-continuation@0.1.0"]`
- Update `evolution_metadata.iteration_history`
- Re-verify all `✅ Verified` claims against current repo HEAD
- Update `provenance.repo.head_commit.sha`
